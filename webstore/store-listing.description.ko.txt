원하는 클라우드 LLM으로 현재 보고 있는 웹페이지를 그 자리에서 바꿔 번역하는 확장 프로그램입니다. Chrome 기본 페이지 번역처럼 원문을 번역문으로 교체하며, 한 번의 클릭으로 원문으로 되돌릴 수 있습니다. 대규모 언어 모델을 사용하므로 문맥을 반영한 자연스러운 번역을 얻을 수 있습니다.

【주요 기능】
・제자리 교체 번역 — 페이지의 원문을 번역문으로 교체하고, 토글로 원문 복원
・여러 LLM 지원 — OpenAI / Anthropic / Google Gemini / xAI 등의 제공업체를 전환(본인의 API 키 사용)
・모델별 추론량 — 지원하는 모델마다 reasoning effort / thinking budget을 기억합니다. 자동 설정은 번역에 맞는 최솟값입니다
・키 없이 체험 — 가입이나 키 없이 MyMemory(무료 NMT) 사용 가능(짧은 문장용, 바로 체험 가능)
・혼합 언어 핀포인트 번역 — 이미 번역 대상 언어인 부분은 그대로 두고, 섞여 있는 다른 언어만 번역
・선택적 설정 동기화 — 브라우저 동기화로 언어, 모델, 표시 설정, 제외 목록을 여러 PC에서 공유합니다. 기본값은 꺼짐이며, API 키, 원문, 번역문은 동기화하지 않습니다
・자동 번역 제외 목록 — URL, 호스트, 와일드카드로 지정한 사이트에서만 자동 번역 중지
・무한 스크롤 / SPA 지원 — 나중에 불러온 부분도 자동으로 번역
・번역 스타일 — 귀엽게, 격식체 등을 선택. 추가 프롬프트는 "사용자 지정"일 때만 적용됩니다
・다시 쓰기 모드 — 번역에 더해, 원래 번역 대상 언어로 작성된 문장을 순화, 격식체, 간사이 사투리 등의 다시 쓰기 스타일로 바꿔 씁니다(LLM 전용)
・선택 텍스트 번역 — 선택한 부분을 Ctrl+Shift+L(Mac은 Command+Shift+L) 또는 마우스 오른쪽 버튼 메뉴로 번역합니다. 말풍선 표시와 인라인(원문·번역문 병기) 표시 중에서 선택할 수 있습니다
・퀵 번역 — 전용 탭에서 짧은 문장을 번역합니다. 페이지 번역과는 별도로 원본 언어와 대상 언어를 설정할 수 있으며, 번역문 복사와 원문·번역문 읽어 주기도 가능합니다
・번역 캐시 — 같은 문맥의 같은 텍스트는 기기 내 캐시에서 재사용하여 API 사용량을 절약합니다. 브라우저를 다시 시작한 뒤에도 쓰는 영구 캐시(최대 30일)는 켰을 때만 저장됩니다
・이미지 속 텍스트 번역(실험적, vision 지원 LLM)
・개인정보 보호 중시 — API 키는 브라우저 내에 로컬로 보관합니다. 텍스트는 선택한 제공업체의 API로만 전송됩니다

【API 키 안내】
이 확장 프로그램은 각 업체의 이용약관에 따라 API 키(API 토큰) 방식으로만 동작합니다. 각 업체 채팅 서비스의 유료 요금제 로그인을 가져다 쓰는 것은 약관 위반이므로 하지 않습니다. 먼저 무료로 사용해 보시려면 무료 사용량이 있는 제공업체나 키가 필요 없는 MyMemory를 추천합니다.

【사용 방법】
1. Chrome 웹 스토어에서 설치합니다
2. 도구 모음의 확장 프로그램 아이콘을 클릭하고 "API 설정" 탭에서 사용할 제공업체의 API 키를 입력합니다(MyMemory는 키가 필요 없습니다)
3. "번역" 탭에서 원본 언어와 대상 언어를 선택하고 "번역"을 누릅니다. 되돌릴 때는 "복원"을 누릅니다
4. 페이지 오른쪽 아래의 플로팅 버튼이나 마우스 오른쪽 버튼 메뉴로도 번역/복원할 수 있습니다
5. "제외 목록" 탭 또는 마우스 오른쪽 버튼 메뉴에서 자동 번역하지 않을 사이트를 추가하거나 삭제할 수 있습니다
6. vision을 지원하는 LLM을 선택하고 이미지 위에 마우스를 올린 뒤 번역 버튼을 누르면 이미지 속 텍스트를 번역합니다(실험적). 이미지 버튼 표시 여부는 "번역" 탭에서 설정할 수 있습니다

【개인정보 보호 안내】
・확장 프로그램 개발자는 데이터를 수집, 저장, 수신하지 않습니다(분석, 추적 없음)
・API 키는 사용자의 브라우저 안(chrome.storage.local)에만 저장됩니다
・번역할 텍스트(이미지 번역 시에는 이미지)는 사용자가 선택한 제공업체의 API로만 전송됩니다
・개발자가 운영하는 서버로는 일절 전송하지 않습니다
・자세한 내용은 개인정보처리방침을 참고하세요
