[Store listing] tab
------------------------------------------------------------

■ Name (max 75 chars)
Replace AI Translator API

■ Summary (max 132 chars)
Translate any page in place with cloud LLMs via your own API key. Natural, context-aware results with one-click restore.

■ Description (max 16,000 chars)

Translate the web page you are viewing in place using the cloud LLM of your choice. Like Chrome's built-in page translation, it replaces the original text with the translation and lets you switch back with one click — but it uses large language models for more natural, context-aware results.

[Features]
- In-place replacement — replace the original text with the translation, toggle back to the original
- Multiple LLM providers — switch between providers such as OpenAI / Anthropic / Google Gemini / xAI using your own API key
- Per-model reasoning control — remember reasoning effort or thinking-budget choices for each supported model; Auto uses the translation-optimized minimum
- No-key option — MyMemory (free NMT) works with no key or signup (best for short text, instant trial)
- Pinpoint mixed-language translation — text already in the target language is left untouched; only the other languages are translated
- Optional settings sync — share languages, models, display preferences, and exclusions across PCs through browser sync. Off by default; API keys and translation data stay out of sync.
- Auto-translate exclusions — skip auto-translate only on sites matching a URL, host, or wildcard rule
- Infinite scroll / SPA friendly — content loaded later is translated automatically
- Translation styles — choose adorable, formal, and other styles; additional prompts apply only with Custom
- Rewrite mode — in addition to translating, rewrites text already written in the target language in a chosen style, such as softening harsh wording or making it formal (LLMs only)
- Selection translation — translate selected text with Ctrl+Shift+L (Command+Shift+L on Mac) or the right-click menu, shown as a bubble or inline next to the original
- Quick translate — a dedicated tab with source and target languages independent of page translation; copy the result or have the source and translation read aloud
- Translation cache — identical text in the same context is reused from an on-device cache to save API usage. The persistent cache, which survives browser restarts (up to 30 days), is saved only when you turn it on
- Image text translation (experimental, vision-capable LLMs)
- Privacy-first — API keys stay local in your browser; text is sent only to the provider you chose

[About API keys]
In line with each provider's terms, this extension works with API keys (API tokens) only. It does not reuse consumer chat-plan logins, which would violate those terms. To try it for free, a provider with a free tier or the no-key MyMemory option is a good start.

[How to use]
1. Install from the Chrome Web Store
2. Click the toolbar icon, open the "API settings" tab, and enter the API key for the provider you want (MyMemory needs no key)
3. In the "Translate" tab, pick the source and target languages, then click "Translate". Click "Restore" to go back
4. You can also toggle translate/restore from the floating button at the bottom-right of the page, or the right-click menu
5. Add or remove sites where auto-translate should stay off from the "Exclusions" tab or the right-click menu
6. Select a vision-capable LLM, then hover an image and click the translate button (experimental). Configure image-button visibility in the "Translate" tab

[Privacy]
- The developer does not collect, store, or receive your data (no analytics, no tracking)
- API keys are stored only inside your browser (chrome.storage.local)
- The text to translate (and images, when image translation is on) is sent only to the provider API you selected
- Nothing is ever sent to the developer's servers
- See the privacy policy for details

[Privacy practices] tab
------------------------------------------------------------

■ Does this item have a single purpose?
Yes

■ Single purpose description
Translate the text of the web page being viewed (optionally including text inside images) with a cloud LLM / NMT API the user chose, and show the translation in place on the page.

■ Data usage disclosure

  - Data types collected (checked):
    - Personally identifiable information
    - Authentication information
    - Personal communications
    - Website content
        Personally identifiable information, personal communications, and authentication information relate to the inquiries the user submits (email address, optional name, subject, message, email verification code) and to the handling of the translation service's API key.
    Website content is the page text (and images, when image translation is enabled) sent to the API of the translation service the user chose, for translation. It is never sent to the developer's servers.

  - Data types not collected:
    Health information, Financial and payment information, Location, Web history, User activity

  - How do you handle user data? (all three checked)
    - Selling user data: No (I do not sell or transfer user data to third parties, outside of the approved use cases)
    - Using or transferring user data for purposes unrelated to the item's single purpose: No (I do not use or transfer user data for purposes that are unrelated to my item's single purpose)
    - Using or transferring user data to determine creditworthiness or for lending: No (I do not use or transfer user data to determine creditworthiness or for lending purposes)

  Certifications: all three checked (see "How do you handle user data?" above).

■ Permission justification

  activeTab:
  Used when the user runs translation from the popup, the right-click menu, or a shortcut, to read the current tab's page content and replace it with the translation result.

  storage:
  Used to save settings (including the auto-translate exclusion list), API keys, token usage, the translation cache, and the auto-tuned batch size inside the browser (chrome.storage.local). Only if the user turns on "Sync settings across PCs", the settings and the exclusion list are also saved to chrome.storage.sync. API keys and translated content are never synced, and are never sent to the developer.

  alarms:
  Retries a settings sync that has not completed. The retry alarm is cleared when sync is turned off.

  scripting:
  Used to inject the translation engine (translator.js) and the selected-text translation script into the frames of the target page only when needed, to translate text and restore the original.

  contextMenus:
  Used to add the following to the right-click menu: translate page, translate selected text, translate image, restore original, and exclude (or stop excluding) this site from auto-translation.

■ Host permission justification

  So that any web page (including local files the user has allowed) can be translated. A translate button and an image-translate button are shown on the page, and requests to the translation APIs are made from the background (service worker) so the API key is never handed to the page. The destinations are the API of the translation service the user chose (for translation and for fetching the model list), models.dev for model pricing information, and support.kagayoi.com when the user submits an inquiry. Page content is never sent to the developer's servers.

■ Are you using remote code?
No
(All code is contained within the extension package; no remote code is loaded or executed. Calls to
translation providers transmit data, not executable code.)
