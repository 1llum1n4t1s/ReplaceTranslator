■ 名前（AMO 50文字以内）
Replace AI Translator API

■ 概要（AMO 250文字以内）
お手持ちの API キーで、クラウド LLM が表示中のページをその場で置換翻訳。原文へワンクリックで復元でき、文脈をふまえた自然な訳が得られます。混在言語のピンポイント翻訳・無限スクロール対応。キー不要の MyMemory で今すぐお試しも可能。

■ 説明
お好みのクラウド LLM を使って、表示中の Web ページをその場で置換翻訳する拡張機能です。Chrome 標準のページ翻訳のように原文を訳文へ差し替え、ワンクリックで原文に戻せます。大規模言語モデルを使うことで、文脈をふまえた自然な翻訳が得られます。

【主な特徴】
・インプレース置換翻訳 — ページの原文を訳文に差し替え、トグルで原文に復元
・各社 LLM 対応 — OpenAI / Anthropic / Google Gemini / xAI などのプロバイダを切り替え（自分の API キーを使用）
・キー不要のお試し — MyMemory（無料 NMT）に登録・キーなしで対応（短文向け・即試せる）
・混在言語のピンポイント翻訳 — すでに翻訳先言語の箇所はそのまま、混ざった別言語だけを翻訳
・無限スクロール / SPA 対応 — 後から読み込まれた部分も自動で翻訳
・クイック翻訳 — ポップアップ内で、ちょっとした文章をその場で翻訳
・画像内テキストの翻訳（実験的・vision 対応 LLM）
・プライバシー重視 — API キーはブラウザ内にローカル保管。テキストは選んだプロバイダの API にのみ送信

【API キーについて】
本拡張は各社の利用規約に従い、API キー（API トークン）方式で動作します。各社チャットサービスの有料プランのログイン流用は規約違反のため行いません。まず試すなら、無料枠のあるプロバイダか、キー不要の MyMemory がおすすめです。
