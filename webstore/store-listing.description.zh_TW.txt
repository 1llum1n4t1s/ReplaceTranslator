使用您選擇的雲端 LLM，將目前瀏覽的網頁就地取代翻譯的擴充功能。如同 Chrome 內建的網頁翻譯，原文會被取代為譯文，並可一鍵還原為原文。藉由大型語言模型，可獲得依據上下文的自然譯文。

【主要功能】
・就地取代翻譯——將網頁原文取代為譯文，可透過切換還原為原文
・支援多家 LLM——可在 OpenAI / Anthropic / Google Gemini / xAI 等服務供應商之間切換（使用您自己的 API 金鑰）
・依模型設定推理量——為每個支援的模型記住 reasoning effort / thinking budget。「自動」使用適合翻譯的最小值
・免金鑰即可試用——無須註冊、無須金鑰，即可使用 MyMemory（免費 NMT）（適合短文，可立即試用）
・混合語言精準翻譯——已是目標語言的部分維持不變，只翻譯混雜的其他語言
・選用的設定同步——透過瀏覽器同步，在多台電腦間共用語言、模型、顯示設定與排除清單。預設為關閉，API 金鑰、原文與譯文不會同步
・自動翻譯排除清單——以 URL、主機名稱或萬用字元指定網站，僅對這些網站停止自動翻譯
・支援無限捲動 / SPA——之後載入的內容也會自動翻譯
・翻譯風格——可選擇可愛風、正式等風格。附加提示詞僅在選擇「自訂」時套用
・改寫模式——除了翻譯之外，也能將原本就是目標語言的句子依溫和、正式、關西腔等改寫風格重新改寫（僅限 LLM）
・選取文字翻譯——選取文字後，按 Ctrl+Shift+L（Mac 為 Command+Shift+L）或透過右鍵選單翻譯。可選擇氣泡顯示或行內（對照）顯示
・快速翻譯——在專用分頁中翻譯短文。可設定與網頁翻譯不同的來源語言與目標語言。支援複製譯文，以及朗讀原文與譯文
・翻譯快取——相同上下文中的相同文字會從裝置內快取重複使用，以節省 API 用量。瀏覽器重新啟動後仍可使用的永久快取（最長 30 天）僅在開啟時才會儲存
・圖片內文字翻譯（實驗性，支援 vision 的 LLM）
・重視隱私——API 金鑰僅儲存在瀏覽器本機。文字只會傳送到您所選服務供應商的 API

【關於 API 金鑰】
本擴充功能遵循各家服務供應商的使用條款，僅以 API 金鑰（API 權杖）方式運作。盜用各家聊天服務付費方案的登入狀態違反條款，因此不會這麼做。若想先免費試用，建議使用提供免費額度的服務供應商，或無須金鑰的 MyMemory。

【使用方式】
1. 從 Chrome 線上應用程式商店安裝
2. 點擊工具列的擴充功能圖示，在「API設定」分頁中輸入所用服務供應商的 API 金鑰（MyMemory 無須金鑰）
3. 在「翻譯」分頁中選擇來源語言與目標語言，然後點擊「翻譯」。要還原時點擊「還原」
4. 也可以透過頁面右下角的浮動按鈕或右鍵選單進行翻譯／還原
5. 可在「排除清單」分頁或右鍵選單中新增、移除不進行自動翻譯的網站
6. 選擇支援 vision 的 LLM 後，將滑鼠游標停在圖片上並點擊翻譯按鈕，即可翻譯圖片內的文字（實驗性）。圖片按鈕的顯示方式可在「翻譯」分頁中設定
