【ストアの掲載情報】タブ
------------------------------------------------------------

■ 名前（75文字以内）
Replace AI Translator API

■ 概要（132文字以内）
お手持ちの API キーで、クラウド LLM がページをその場で置換翻訳。原文へワンクリック復元、文脈をふまえた自然な訳。混在言語のピンポイント翻訳・無限スクロール対応。キー不要の MyMemory で即お試し。

■ 説明（16,000文字以内）

お好みのクラウド LLM を使って、表示中の Web ページをその場で置換翻訳する拡張機能です。Chrome 標準のページ翻訳のように原文を訳文へ差し替え、ワンクリックで原文に戻せます。大規模言語モデルを使うことで、文脈をふまえた自然な翻訳が得られます。

【主な特徴】
・インプレース置換翻訳 — ページの原文を訳文に差し替え、トグルで原文に復元
・各社 LLM 対応 — OpenAI / Anthropic / Google Gemini / xAI などのプロバイダを切り替え（自分の API キーを使用）
・キー不要のお試し — MyMemory（無料 NMT）に登録・キーなしで対応（短文向け・即試せる）
・混在言語のピンポイント翻訳 — すでに翻訳先言語の箇所はそのまま、混ざった別言語だけを翻訳
・自動翻訳の除外リスト — URL・ホスト・ワイルドカードで指定したサイトだけ自動翻訳を停止
・無限スクロール / SPA 対応 — 後から読み込まれた部分も自動で翻訳
・クイック翻訳 — ポップアップ内で、ちょっとした文章をその場で翻訳
・画像内テキストの翻訳（実験的・vision 対応 LLM）
・プライバシー重視 — API キーはブラウザ内にローカル保管。テキストは選んだプロバイダの API にのみ送信

【API キーについて】
本拡張は各社の利用規約に従い、API キー（API トークン）方式で動作します。各社チャットサービスの有料プランのログイン流用は規約違反のため行いません。まず無料で試すなら、無料枠のあるプロバイダか、キー不要の MyMemory がおすすめです。

【使い方】
1. Chrome Web Store からインストール
2. ツールバーの拡張機能アイコンをクリックし、「API設定」タブで使うプロバイダの API キーを入力（MyMemory はキー不要）
3. 「翻訳」タブで翻訳元・翻訳先を選び「翻訳」。原文に戻すときは「復元」
4. ページ右下のフローティングボタン（訳 ⇄ 原）や、右クリックメニューからも翻訳/復元できます
5. 「除外リスト」タブ、または右クリックメニューから、自動翻訳しないサイトを追加・削除できます
6. 「API設定」で画像翻訳を ON にすると、画像にホバーして「訳」ボタンで画像内テキストを翻訳（実験的・vision 対応 LLM）

【プライバシーについて】
・拡張機能の開発者はデータを収集・保存・受信しません（解析・トラッキングなし）
・API キーはお使いのブラウザ内（chrome.storage.local）にのみ保存されます
・翻訳対象のテキスト（画像翻訳時は画像）は、利用者が選んだプロバイダの API にのみ送信されます
・開発者が運営するサーバーには一切送信しません
・詳細はプライバシーポリシーを参照してください

【プライバシーへの取り組み】タブ
------------------------------------------------------------

■ このアイテムに単一の目的はありますか？
はい

■ 単一の目的の説明
表示中の Web ページのテキスト（および任意で画像内テキスト）を、利用者が選んだクラウド LLM / NMT API で翻訳し、ページ上にインプレースで置換表示する。

■ データの使用に関する開示

  ・個人を特定できる情報を収集しますか？
    いいえ

  ・ユーザーのデータをどのように扱いますか？
    - ユーザーデータの販売: しない
    - ユーザーデータの本来の目的以外への使用や転送: しない
    - 信用力の判定や貸付目的での使用や転送: しない

■ 権限の正当性

  activeTab:
  ユーザーがポップアップ / 右クリックメニューから翻訳を実行した際に、現在のタブのページ内容を
  読み取り、翻訳結果で置換するために使用します。

  storage:
  設定（自動翻訳対象外リストを含む）・API キー・トークン使用量・自動学習したバッチサイズをローカル（chrome.storage.local）に
  保存するために使用します。

  scripting:
  翻訳エンジン（translator.js）を対象ページの全フレームにオンデマンド注入し、テキストノードを
  翻訳・復元するために使用します。

  contextMenus:
  右クリックメニューにページ翻訳・原文復元・自動翻訳対象外の追加/削除を表示するために使用します。

  host_permissions (<all_urls>):
  あらゆる Web ページを翻訳できるようにするため、対象ページへのスクリプト注入と、選んだプロバイダ
  API への通信（API キーをページ文脈に晒さず background から代理 fetch）に使用します。

■ リモートコードを使用していますか？
いいえ
（すべてのコードは拡張機能パッケージ内に含まれており、外部からのコード読み込みは行いません。翻訳 API への
通信はデータ送受信であり、リモートコードの実行ではありません。）
