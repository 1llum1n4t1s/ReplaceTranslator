使用您选择的云端 LLM，将当前浏览的网页就地替换翻译的扩展程序。与 Chrome 自带的网页翻译一样，原文会被替换为译文，并可一键还原为原文。借助大语言模型，可获得结合上下文的自然译文。

【主要功能】
・就地替换翻译——将网页原文替换为译文，可通过切换还原为原文
・支持多家 LLM——可在 OpenAI / Anthropic / Google Gemini / xAI 等服务商之间切换（使用您自己的 API 密钥）
・按模型设置推理量——为每个受支持的模型记住 reasoning effort / thinking budget。“自动”使用适合翻译的最小值
・无需密钥即可试用——无需注册、无需密钥，即可使用 MyMemory（免费 NMT）（适合短文本，可立即试用）
・混合语言精准翻译——已是目标语言的部分保持不变，只翻译混杂的其他语言
・可选的设置同步——通过浏览器同步，在多台电脑间共享语言、模型、显示设置和排除列表。默认关闭，API 密钥、原文和译文不会同步
・自动翻译排除列表——按 URL、主机名或通配符指定网站，仅对这些网站停止自动翻译
・支持无限滚动 / SPA——后续加载的内容也会自动翻译
・翻译风格——可选择可爱、正式等风格。附加提示词仅在选择“自定义”时生效
・改写模式——在翻译之外，还可将原本就是目标语言的句子按温和、正式、关西方言等改写风格重新改写（仅限 LLM）
・选中文本翻译——选中文本后，按 Ctrl+Shift+L（Mac 为 Command+Shift+L）或通过右键菜单翻译。可选择气泡显示或行内（对照）显示
・快译——在专用标签页中翻译短文本。可设置与网页翻译不同的源语言和目标语言。支持复制译文，以及朗读原文和译文
・翻译缓存——相同上下文中的相同文本会从设备内缓存中复用，以节省 API 用量。重启浏览器后仍可使用的持久缓存（最长 30 天）仅在开启时才会保存
・图片内文字翻译（实验性，支持 vision 的 LLM）
・注重隐私——API 密钥仅保存在浏览器本地。文本只会发送到您所选服务商的 API

【关于 API 密钥】
本扩展程序遵循各家服务商的使用条款，仅通过 API 密钥（API 令牌）方式工作。盗用各家聊天服务付费套餐的登录状态违反条款，因此不会这样做。若想先免费试用，推荐使用提供免费额度的服务商，或无需密钥的 MyMemory。

【使用方法】
1. 从 Chrome 应用商店安装
2. 点击工具栏中的扩展程序图标，在“API设置”标签页中输入所用服务商的 API 密钥（MyMemory 无需密钥）
3. 在“翻译”标签页中选择源语言和目标语言，然后点击“翻译”。需要还原时点击“还原”
4. 也可以通过页面右下角的悬浮按钮或右键菜单进行翻译/还原
5. 可在“排除”标签页或右键菜单中添加、删除不进行自动翻译的网站
6. 选择支持 vision 的 LLM 后，将鼠标悬停在图片上并点击翻译按钮，即可翻译图片内的文字（实验性）。图片按钮的显示方式可在“翻译”标签页中设置

【隐私说明】
・扩展程序开发者不会收集、保存或接收数据（无分析、无跟踪）
・API 密钥仅保存在您的浏览器内（chrome.storage.local）
・待翻译的文本（翻译图片时为图片）只会发送到您所选服务商的 API
・不会向开发者运营的服务器发送任何内容
・详情请参阅隐私政策
