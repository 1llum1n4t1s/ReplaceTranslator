収集する情報

本拡張機能の開発者は、翻訳の動作から利用者のデータを収集・保存・受信しません。解析ツールやトラッキングも一切使用しません。翻訳するテキスト（および画像翻訳を有効にした場合は画像）は、利用者が選んだ翻訳プロバイダにのみ送信されます（詳細は下記「翻訳対象テキストの扱い」「画像翻訳（任意）」を参照）。

例外は、利用者が自分でお問い合わせフォームを送信したときだけです。このときに限り、入力されたメールアドレスと問い合わせ内容が開発者（Kagayoi）のサポート窓口へ送信されます（下記「お問い合わせフォーム」を参照）。

API キーの扱い

  • 各 LLM プロバイダ（OpenAI / Anthropic / Google / xAI）の API キーは、お使いのブラウザ内（chrome.storage.local）にのみ保存されます。MyMemory はキー不要です。
  • API キーは、翻訳実行時に該当プロバイダの API へ認証目的でのみ送信されます。本拡張機能の開発者を含む第三者には一切送信されません。

設定の同期（任意）

競合解決のため変更時刻・論理カウンター・拡張内で生成したランダムな端末IDも同期します。削除した除外ルールと推論量の記録は、古い端末からの復活を防ぐため保持します。PC名やハードウェア識別子は使用しません。

「複数PCで設定を同期」は既定OFFです。各PCでONにすると、言語・翻訳サービス・モデル・推論量・表示設定・自動翻訳と除外リストをブラウザー提供元の同期機能で同じアカウントのPC間で共有します。開発者のサーバーは経由しません。APIキー・原文・訳文・キャッシュ・使用量・永続キャッシュの保存同意は同期しません。OFFにするとその端末での同期を停止し、ローカルと同期先の設定は残ります。同期データの取り扱いはブラウザー提供元のプライバシーポリシーに従います。

翻訳対象テキストの扱い

  • 「翻訳」を実行したとき、ページ上のテキストは、利用者が選択したプロバイダの API にのみ送信され、翻訳結果を受け取ります。
  • 送信先での扱いは、各プロバイダのプライバシーポリシー・利用規約に従います:
  • OpenAI: https://openai.com/policies/
  • Anthropic: https://www.anthropic.com/legal
  • Google AI: https://ai.google.dev/gemini-api/terms
  • xAI (Grok): https://x.ai/legal/privacy-policy
  • MyMemory (Translated): https://mymemory.translated.net/doc/en/tos.php
  • 本拡張機能の開発者が運営するサーバーには、翻訳対象のテキストを一切送信しません（送信先は利用者が選んだプロバイダの API のみ）。開発者のサーバーへ送るのは、利用者が自分でお問い合わせフォームに入力した内容だけです。

画像翻訳（任意）

  • 画像翻訳は、利用者がその画像を明示的に操作した（画像上のボタンをクリックした、または右クリックメニューで「この画像を翻訳」を選んだ）ときにのみ動作します。その 1 枚の画像が取得され、選択中の vision 対応プロバイダの API に画像データとして送信され、画像内のテキストを読み取って翻訳します。ページ上の画像を自動で一括送信することはありません。
  • 送信先での扱いは、上記と同じ各プロバイダのプライバシーポリシー・利用規約に従います。MyMemory は画像翻訳に非対応です。

トークン使用量

  • トークン使用量は、お使いのブラウザ内（chrome.storage.local）に月別で保存されるだけで、外部には送信されません。

お問い合わせフォーム

設定画面の「お問い合わせ」ボタンから送信したときだけ、次の情報を Kagayoi Support（https://support.kagayoi.com）へ送信します。ボタンを押さない限り、この通信は発生しません。

  • 入力されたメールアドレス、お名前（任意）、問い合わせ種別、件名、本文
  • 製品ID、拡張機能のバージョン、ロケール

初回はメールで届く6桁の確認コードを Kagayoi Support へ送信して本人確認します。認証後の問い合わせと返信は、利用者本人とサポート担当者が確認できるよう Kagayoi Support に保存します。翻訳対象のテキスト、画像、API キー、トークン使用量は送信しません。

権限の用途

  • storage: 設定・API キー・トークン使用量のローカル保存と、利用者が有効化した場合の設定同期
  • alarms: 設定同期が完了しない場合の再試行（同期OFFで解除）
  • scripting / activeTab / host_permissions: 翻訳対象ページへのスクリプト注入と、選択したプロバイダ API への通信
  • contextMenus: 右クリックメニューからのページ翻訳 / 選択テキスト翻訳 / 画像翻訳 / 原文復元
